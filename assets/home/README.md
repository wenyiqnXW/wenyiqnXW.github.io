# WangHaHa Personal Homepage

这是 WangHaHa 的个人主页子站点，用来展示个人介绍、履历经历、项目实践与技术博客导航。当前站点部署在 GitHub Pages 仓库 `wenyiqnXW/wenyiqnXW.github.io` 中。

## 页面结构

- `index.html`：个人主页，展示基础信息、研究方向和履历入口。
- `resume.html`：履历页，包含教育经历、研究方向、项目经历和工作经历。
- `blog.html`：博客导航页，聚合 CSDN 技术文章入口。
- `live.html`：其他内容页，目前保留为后续内容扩展区域。
- `contact.html`：已隐藏，直接访问时会自动回到主页。

- 研究生：湖南大学，研二。
- 研究方向：高性能网络、RDMA。
- 技术背景：Java 后端开发、Spring Boot、MyBatis、Redis、消息队列、分布式服务基础。

## 本地预览

直接打开 `assets/home/index.html` 即可预览个人主页。若需要通过本地服务访问，可在仓库根目录启动静态服务器后访问 `assets/home/index.html`。

## 维护说明

- 新增博客时，优先更新 `blog.html` 中的文章卡片和时间归档。
- 新增经历时，优先更新 `resume.html` 中的时间线。
- 如果恢复独立沟通页面，需要重新在各页面导航栏中加入对应入口。
